## On-page rules

- Primary keyword appears naturally in title, H1, opening paragraph and one useful H2 when appropriate.
- Meta titles should generally stay compact enough to avoid obvious truncation; no keyword-stuffed pipe chains.
- Meta descriptions explain the actual unique value of the page and mention evidence status where useful.
- Only one H1.
- H2s model user tasks/questions; H3s break down entity fields or steps.
- First screen should answer the query before lore/background.
- Do not publish generated filler simply to reach a word count.
- All factual tables include source/evidence linkage at the record or section level.

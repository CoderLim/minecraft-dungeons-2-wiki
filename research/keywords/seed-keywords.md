## Consolidation rules

Do not make separate pages for grammatical variants with the same intent:
- release / release date / when does it come out → `/release-date/`
- price / cost / how much → `/price/`
- sift / the sift / sift minecraft → `/the-sift/`
- cross platform / crossplay → `/crossplay/`

Independent named entities get their own pages.

## Exclude from Dungeons II core taxonomy
Adjacent trend terms such as NameMC, Kinguin and unrelated Minecraft cape/event entities should not be promoted to Dungeons II pages without a real game relationship.
